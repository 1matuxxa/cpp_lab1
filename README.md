# Задание 1 - Методы
## Задача 2 - Сумма знаков
### Текст задачи
Дробная часть.
Дана сигнатура функции: double fraction (double x);
Необходимо реализовать функцию таким образом, чтобы она возвращала
только дробную часть числа х. Подсказка: вещественное число может быть
преобразовано к целому путем отбрасывания дробной части.
### Алгоритм решения
Функция берет переданное число по модулю с помощью std::abs. Затем с помощью операции взятия остатка от деления на 10 вычисляется последняя цифра. Предпоследняя цифра находится путем деления числа на 10 и последующего взятия остатка от деления на 10. В качестве результата возвращается их сумма.
